# Student API - Spring Boot

A beginner-level REST API built using Spring Boot.

## Technologies

- Java
- Spring Boot
- Maven
- REST API

## Features

- Get student information
- Return student data as JSON
- Basic Controller and Service architecture

## API Endpoint

GET /api/v1/student

## How to Run

1. Clone the repository
2. Open the project in IntelliJ IDEA
3. Run the Spring Boot application
4. Open:
   http://localhost:8080/api/v1/student
